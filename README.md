# 🪄 Hogwarts House Selection

A magical **House Selection Game** inspired by the Wizarding World ✨

Answer a series of questions, and let the Sorting Hat decide which house matches your choices.

## 🏰 Houses

* 🦁 **Gryffindor** — Courage & Bravery
* 🐍 **Slytherin** — Ambition & Determination
* 🦅 **Ravenclaw** — Wisdom & Creativity
* 🦡 **Hufflepuff** — Loyalty & Kindness

## ✨ Features

* 🎩 Interactive Sorting Hat
* 🪄 House selection based on answers
* ✨ Magical particle effects
* 🎵 Interactive sound effects
* 🏰 House-specific themes
* 📱 Responsive design
* 🔄 Choose your house again

## 🛠️ Built With

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/hindhuja-143/hp.git
```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Begin the ceremony! 🪄

## 🎮 How It Works

**Start the Ceremony → Answer the Questions → Sorting Hat Thinks → Discover Your House**
